# Erick Gatica Candia · Professional & Research Website

Static site (HTML/CSS/vanilla JS, no build step) for GitHub Pages.
Live: https://erickgatica.github.io/Pro_website_ErickG/ · Plan: [plan/IMPLEMENTATION_PLAN.md](plan/IMPLEMENTATION_PLAN.md)

The home page opens with a live physics simulation: a laser crosses a gas of H₂O molecules and the H₂O spectrum near 1469 nm is computed line by line in the browser from HITRAN data (direct absorption, WMS-2f and dual-comb modes).

## Run locally

```bash
python3 -m http.server 8000      # from this folder
# open http://localhost:8000
```
Opening `index.html` directly won't work (browsers block module scripts and `fetch` from `file://`).

## Common edits

| I want to… | Do this |
|---|---|
| Change text, links or email | `src/js/config.js` |
| Add a paper | Add an entry to `src/data/publications.json` (with DOI) and list its id in the project's `publications` in `projects.json` |
| Add paper figures | Add entries to `tools/figures.json`, put the PDF in `resources/`, run `python3 tools/export_figures.py`, then list the figure ids in the project's `figures` |
| Add a research project | Add an object to `src/data/projects.json` (`status`: current / upcoming / published) |
| Publish the algebra book PDF | Copy it to `assets/docs/Complemento_de_Algebra.pdf` and set `"pdf": "assets/docs/Complemento_de_Algebra.pdf"` in `src/data/other-projects.json`. Re-run `python3 tools/export_site_images.py` to refresh page previews |
| Update the CV | Replace `assets/docs/CV_Erick_Gatica.pdf` and edit `src/data/cv.json` |

## Tools (Python)

Install once: `pip install pymupdf pillow numpy hitran-api`

| Script | What it does |
|---|---|
| `tools/export_figures.py` | Crops figures from paper PDFs → WebP + `figures.json` |
| `tools/export_site_images.py` | Profile crops, social preview image, book page previews |
| `tools/build_spectral_data.py` | Downloads H₂O lines from HITRAN → `spectra.json` + test references |
| `tools/check_content.py` | Checks DOIs resolve, figures exist, ids match (run before publishing) |

## Tests

With the local server running:
- `/tests/physics.test.html`: JS physics vs HITRAN/HAPI (must show **ALL PASS**, within 2 %; currently ≤ 0.7 %)
- `/tests/responsive.html?route=%23/cv`: the site at phone widths
- `/tests/hero-modes.html?mode=dualcomb&T=1800`: hero in a given mode and state

## Notes on choices

- **No KaTeX:** the few equations are hand-set HTML with styled terms, so each term can "light up" when its slider moves and the home page avoids an extra ~75 KB.
- **Figures, not PDFs:** paper figures are shown with a credit line and DOI; the papers themselves stay in `resources/` (git-ignored).
- **Visual gain:** real peak absorbance is ~0.1, so the beam dimming and absorption flashes in the scene are amplified for visibility. The plot and every number shown are the true values.

## Deploy

Push to `main`, then in the GitHub repo: **Settings → Pages → Deploy from a branch → `main` / `(root)`**.
